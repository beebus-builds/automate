# Teacher Portfolio Website Generator

A CMS-based system to generate personalized teacher portfolio websites.

## How It Works

1. Open `cms/cms.html` in a browser — the CMS admin panel
2. Edit your content through the visual interface (tabs for each section)
3. Click **Download JSON** to save `data.json` to the project root
4. Run `npm run build` to generate the website in `dist/`
5. Open `dist/index.html` to see your live site

## Quick Start

```bash
npm run build   # generates the website in dist/
```

Then open `dist/index.html` in a browser.

## CMS Workflow

The CMS panel (`cms/cms.html`) gives teachers a visual editing experience:

- **Tab-based navigation** — General, Hero, About, Courses, Philosophy, Achievements, Contact, Theme
- **Live preview** — see changes in real time in a side panel
- **Add/remove items** — dynamically add or remove courses, achievements, philosophy points
- **Save & export** — download `data.json` to the project root
- **Build** — download `data.json` and regenerate the website

## What You Can Customize

| Section | Fields |
|---|---|
| **General** | Site title |
| **Hero** | Tagline, title, highlighted word, description, avatar initials |
| **About** | Bio lead, paragraphs, stats (number/suffix/label) |
| **Courses** | Add/remove courses (icon emoji, title, description, level) |
| **Philosophy** | Quote, attribution, points (title + description) |
| **Achievements** | Year, title, description per item |
| **Contact** | Email, phone, location |
| **Theme** | Primary color, accent color |

## Project Structure

```
cms/              ← CMS admin panel (open cms/cms.html to edit)
  cms.html        ← Admin interface
  cms.css         ← Admin styles
  cms.js          ← CMS logic

index.html        ← Website HTML template (build source)
css/style.css     ← Stylesheet template (build source)
js/script.js      ← Interactive features

build.js          ← Build script (do not edit)
package.json      ← NPM config
data.json         ← Content data (generated by CMS, used by build)
dist/             ← Generated website (auto-created, gitignored)
```
